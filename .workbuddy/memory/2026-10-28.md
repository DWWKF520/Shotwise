## 环境问题排查（WSL2）

- `go` 命令找不到：实际装在 `~/.local/go`（go1.26.10），`.bashrc:141` 有 PATH 导出但受顶部非交互守卫影响未生效，`source ~/.bashrc` 或重开终端即可；不要用 apt 装（源里只有 1.21 会降级）。`cmd/shotwised` 在 `server-go/` 子目录下，须 `cd server-go && go run ./cmd/shotwised`。
- 宿主机访问不到 18080：①`shotwised` 默认 `LISTEN_HOST=127.0.0.1`（`internal/config/config.go`），须 `LISTEN_HOST=0.0.0.0` 启动；②WSL2 localhost 转发 relay 失效（`.wslconfig` 已设 `localhostForwarding=true` 仍不通），当前 workaround 是宿主机走 WSL IP http://172.28.145.227:18080/（NAT 模式 IP 会变），彻底修复需 Windows 侧 `wsl --shutdown` 后重启 WSL。
