## 修复：创意画布「每次新建弹『同名文件已存在』」+ creative_board_not_found 卡死（前端）

- 现象：①每次新建画布后编辑（拖节点/平移）必弹 ConflictModal「同名文件已存在」；②URL `?board=` 指向已删画布时整个工作台卡死报裸码 `creative_board_not_found`。
- 诊断链路（均在 `frontend/src/components/canvas/CreativeBoardWorkspace.tsx`）：
  - 后端建板无重名校验（Go `creative_board.go::CreateBoard` / Python 同），“已存在”弹窗实为 409 `creative_board_revision_conflict` 误配的标题（`ConflictModal` 的 `conflict_modal_title`）。
  - 确定性根因：新建画布自动弹重命名框 → `saveBoardOptionName` 调 `updateCreativeBoard` 不带 `expected_revision` 且丢弃响应 revision → 服务端版本 +1、前端 `revisionRef` 持旧值 → 下一次自动保存 409 → 冲突框。
  - 竞态根因：`revisionRef` 全局单值跨板共享，旧板在途保存的响应晚到会把旧板 revision 写回污染当前板；反向亦然（在途保存读了新板 revision 去写旧板）。
  - 404 根因：`deleteBoard` 删后不导航（URL/`board` 态仍指已删板，后续自动保存全 404）；`load()` 优先用 URL 的 stale boardId，getCreativeBoard 404 即硬失败不降级。
  - 放大器：`isCreativeBoardRevisionConflict` 裸判 `status===409`（creative_context 的 `creative_board_not_found` 在 Go 侧也是 409，会被误弹成“已存在”）；`request()` 抛裸 `Error` 丢掉结构化 detail，`getCreativeBoardConflictRevision` 永远拿不到 `current_revision`。
- 修复（`frontend/src/api.ts` + `CreativeBoardWorkspace.tsx`，已过 lint/typecheck/全量 2099 用例）：
  - `ApiHttpError` 携带 `detail`；`request()`/`throwIfNotOk()` 抛 `ApiHttpError`（Error 子类，`detail.code`/`current_revision` 可达）。
  - `isCreativeBoardRevisionConflict` 改按 code 判定，不再裸认 409。
  - `revisionRef` → `boardRevisionsRef`（Map 按 boardId）+ `currentBoardIdRef` 守护 `setRevision`（`persistSnapshot::applyRevision`、`resolveConflict`、load 均按板读写）。
  - `saveBoardOptionName` 带 `expected_revision: boardRevisionsRef.current.get(option.id)` 并经 `applyBoardRevision` 回写返回 revision。
  - `deleteBoard` 删当前板后 `navigateToBoard(remaining[0])`，全删完 `clearBoardParam()` 触发自动建板。
  - `load()` 对 URL boardId 的 404 降级取列表首个/自动建板（`isCreativeBoardNotFoundError` 本地判定）。
  - 持久化 key 去 revision（`boardPersistenceKey`），保存成功不再触发一轮无操作 flush。
  - 测试：mock 工厂补 `createCreativeBoard`/`updateCreativeBoard`；新增「URL 板 404 降级」「新建画布重命名带 expected_revision=1」两个用例（此前创建/重命名路径零测试覆盖）。
- 有意不改：`canvasPersistence.ts` 原计划加 `resetKey`，核实 load 期间 `hydrated=false` 已走基线重置分支，加了是死代码，未动。
- 遗留建议（涉及 API 契约，单独开 issue）：Go creative_context 用 409 传 `creative_board_not_found`（语义应为 404）；该字面量无 i18n key，用户可见裸码。
